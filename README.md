This repository is a program that writes one short text for make.fun's bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`, roasts a gadget or app you use every day in a single line of at most 200 characters, and writes that line to `entry.txt` in the output folder.

```text
My watch congratulated me on a twelve-hour stand goal I hit standing at the fridge.
```

Run it with:

```console
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
